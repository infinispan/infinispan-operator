= Upgrading {ispn_operator}

[role="_abstract"]
Upgrading {ispn_operator} updates the controller that manages your {brandname} clusters.
This is separate from upgrading the {brandname} server version, and the two have different triggers and effects on running clusters.

[IMPORTANT]
====
Upgrading {ispn_operator} does *not* upgrade the {brandname} server version.
Server versions are controlled independently through the `spec.version` field in your `Infinispan` CR.
For information about server upgrades, see xref:cluster-upgrades_upgrading-clusters[{brandname} cluster upgrades].
====
