= Configuring the security context

[role="_abstract"]
Customize the pod-level and container-level security context that {ispn_operator} applies to {brandname} workloads.
Your configuration is deep-merged over the operator defaults.

.Procedure

. Add the `spec.securityContext` field to your `Infinispan` CR to configure the pod-level security context.
. Add the `spec.container.securityContext` field to your `Infinispan` CR to configure the container-level security context.

[NOTE]
====
Batch jobs, as well as backup and restore pods, inherit the security context of the target {brandname} cluster and do not have configurable security context fields of their own.
