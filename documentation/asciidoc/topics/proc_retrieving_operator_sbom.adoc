= Retrieving the Software Bill of Materials for {ispn_operator}

[role="_abstract"]
Retrieve the _Software Bill of Materials_ (SBOM) for {ispn_operator} to audit the contents of the image before you install it.
Each {ispn_operator} release image carries an SPDX SBOM for every architecture it supports.
The SBOM is attached to the image as an OCI attestation, so you do not need to download or run the image to inspect it.

.Prerequisites

* Install link:https://docs.docker.com/reference/cli/docker/buildx/[Docker Buildx].
